🤖

Multi-Agent Orchestration

LangGraph cho phép xây dựng 10+ AI agents hoạt động phối hợp: Planning Agent, Search Agent, Weather Agent, Route Agent, Budget Agent...

Stateful Workflows

Quản lý state phức tạp với checkpoints và persistence. Agents có thể "nhớ" context và tiếp tục workflow ngay cả khi bị gián đoạn.

Tool Integration

🎯

Human-in-the-Loop

Vi Vu Multi-Agent System Architecture

01

🎯 Planning Agent

Nhận input từ user (điểm đến, ngày, ngân sách), phân tích requirements và tạo execution plan.

🌦️ Weather Agent

🗺️ Route Agent

06

✨ Optimization Agent

Review toàn bộ itinerary, tối ưu thời gian, chi phí, trải nghiệm. Generate final recommendations.

Code Example - LangGraph Multi-Agent Workflow

# agents/workflow.py - Vi Vu Multi-Agent Graph
from langgraph.graph import StateGraph, END
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage

# Define state
class TravelPlanState(TypedDict):
    input: str
    destination: str
    budget: float
    weather_info: dict
    places: list
    route: dict
    itinerary: dict
    final_plan: str

# Initialize LLM
llm = ChatOpenAI(model="gpt-4-turbo-preview", temperature=0.7)

# Create workflow graph
workflow = StateGraph(TravelPlanState)

# Add agent nodes
workflow.add_node("planner", planning_agent)
workflow.add_node("weather", weather_agent)
workflow.add_node("search", search_agent)
workflow.add_node("router", route_agent)
workflow.add_node("budget", budget_agent)
workflow.add_node("optimizer", optimization_agent)

# Define edges (agent flow)
workflow.set_entry_point("planner")
workflow.add_edge("planner", "weather")
workflow.add_edge("weather", "search")
workflow.add_edge("search", "router")
workflow.add_edge("router", "budget")
workflow.add_edge("budget", "optimizer")
workflow.add_edge("optimizer", END)

# Compile graph
app = workflow.compile()

# Execute
result = app.invoke({
    "input": "Plan 3-day trip to Da Nang, budget 10M VND"
})

🎯 Tính năng đặc biệt trong Vi Vu

  • Conditional Routing: Agents tự động routing dựa trên context (budget cao → premium places)
  • Error Handling: Retry logic với exponential backoff khi API call fails
  • Parallel Execution: Weather + Search agents chạy song song để giảm latency
  • Memory: ConversationBufferMemory lưu chat history để personalize recommendations
  • Streaming: Stream từng bước của workflow đến frontend real-time
  • LangSmith Integration: Full observability với traces, metrics, và debugging
