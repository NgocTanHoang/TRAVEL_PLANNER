🎯 RAG Workflow trong Vi Vu

  • 1. Embedding: OpenAI text-embedding-3-small chuyển 50K+ địa điểm → 1536-dim vectors
  • 2. Store: ChromaDB lưu vectors + metadata (province, category, rating, price)
  • 3. Query: User input "bãi biển đẹp ở Đà Nẵng" → embedding → search ChromaDB
  • 4. Retrieve: Top 10 most similar places (cosine similarity > 0.8)
  • 5. Augment: Inject retrieved data vào GPT-4 prompt với context
  • 6. Generate: GPT-4 tạo itinerary dựa trên real data, không hallucinate

💡 Tại sao RAG > Fine-tuning?

  • Real-time Updates: Add/update places instantly, không cần retrain model
  • Cost-effective: $0.0001/1K tokens vs $0.008/1K for fine-tuning GPT-4
  • No Hallucination: Dữ liệu luôn grounded in facts từ database
  • Explainable: Biết rõ source nào được sử dụng trong response
  • Flexible: Dễ dàng thay đổi data source (ChromaDB → Pinecone → Weaviate)

🔧 Tech Stack - ChromaDB Integration
